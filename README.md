# 💬 AI-Powered Sentiment Analysis System

An NLP + Machine Learning project that classifies customer reviews as:

- 😊 Positive
- 😐 Neutral
- 😞 Negative

Built and deployed using Streamlit : https://sentiment-analysis-o8zwy2iujnohpdtgzhcuda.streamlit.app/

## 🎯 Objectives

- Clean and preprocess review text
- Perform EDA
- Convert text using TF-IDF
- Train and compare ML models
- Evaluate using Accuracy, Precision, Recall and F1-score
- Apply Cross Validation and Grid Search
- Build and save an ML pipeline
- Deploy the application using Streamlit

## 📊 Dataset

The dataset contains **10,000 customer reviews** with:

- `review_id`
- `review_text`
- `sentiment`
- `category`
- `source`
